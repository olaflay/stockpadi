# Research and plan pointer

The former standalone `RESEARCH-AND-PLAN.md` was consolidated into the
audited product documents. This compatibility pointer keeps older code and
decision references resolvable without creating a second product authority.

Use these current sources instead:

- vetted product and improvement decisions: `docs/complete-improvement-audit.md`
- pending research and unresolved implementation specs:
  `docs/PENDING-TASKS-AND-RESEARCH.md`
- launch boundary and verification status: `docs/LAUNCH_SCOPE.md`
- product requirements and locked behavior: `docs/PRD.md`
- feature-specific evidence: `docs/research/` and `docs/specs/`

This file is a documentation compatibility layer only. New decisions must be
recorded in the current source that owns the topic, not added here.
